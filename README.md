```text
portfolio-infor1-iagofonseca/
```

- **`index.html`** — porta de entrada do site.
- **`sobre.html`** — conta um pouco sobre mim.
- **`contato.html`** — reúne os meios de contato.

## 🔨 Construção do projeto

<details>
<summary><b>Ver as etapas de construção</b></summary>

1. **Estrutura das páginas:** criação dos arquivos `index.html`, `sobre.html` e `contato.html`, cada um com a estrutura básica do HTML5.
2. **Organização dos arquivos:** estilos separados na pasta `css/` e imagens na pasta `img/`.
3. **Estilização:** aplicação de CSS nas páginas para definir o visual do portfólio.
4. **Navegação:** ligação entre as páginas por meio de links.
5. **Versionamento:** envio do projeto ao GitHub, com commits ao longo do desenvolvimento.
6. **Publicação:** ativação do GitHub Pages para deixar o portfólio acessível online.

</details>

## ▶️ Como executar

Escolha a opção que preferir:

<details>
<summary><b>🌐 Opção 1 — Acessar online (mais rápido)</b></summary>

Basta abrir o link: [iagofonsecaregis.github.io/portfolio-infor1-iagofonseca](https://iagofonsecaregis.github.io/portfolio-infor1-iagofonseca/)

</details>

<details>
<summary><b>💻 Opção 2 — Rodar localmente</b></summary>

1. Clone o repositório:

   ```bash
   git clone https://github.com/iagofonsecaregis/portfolio-infor1-iagofonseca.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd portfolio-infor1-iagofonseca
   ```

3. Abra o arquivo `index.html` no seu navegador (duplo clique ou arrastando o arquivo para a janela do navegador).

</details>

<details>
<summary><b>⬇️ Opção 3 — Baixar em ZIP</b></summary>

1. Acesse o [repositório](https://github.com/iagofonsecaregis/portfolio-infor1-iagofonseca).
2. Clique em **Code → Download ZIP**.
3. Extraia os arquivos e abra o `index.html`.

</details>
